# Laddrix brand

**Laddrix** is named after the price ladder, the heart of the app. Ayush chose the name on 25 Oct 2026 (#457).

| File | Use |
|------|-----|
| [`ui/public/favicon.svg`](../../ui/public/favicon.svg) | the mark: the browser tab, the app's menu bar, posters |
| [`laddrix-logo.svg`](laddrix-logo.svg) | the mark with the word, for the README, docs and slides |
| [`laddrix-logo.png`](laddrix-logo.png) | the same, as a picture |

**The mark** is a price ladder inside a hexagon:
- the two rose rungs are the asks (sellers);
- the bright cyan rung is the last traded price;
- the two green rungs are the bids (buyers).

The edge runs from cyan to violet, the same gradient as the posters.
