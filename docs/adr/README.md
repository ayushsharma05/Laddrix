# Decisions

MockTrade doesn't keep separate decision records. Each decision is written where it is used:

- **Why and when:** `context/conversation-log.md`, dated, with what was asked, what was decided and why.
- **What the design is now:** the docs in `docs/design/`. Start at [kite-architecture.md](../design/kite-architecture.md) and [product-vision.md](../design/product-vision.md).
